# Taskeen Meher — Portfolio

A recruiter-first portfolio for a Technical Project Manager working in the Shopify and Shopify Plus ecosystem.

## Highlights

- Single-page, responsive experience designed for a fast 30-second scan
- Resume-backed impact metrics and career timeline
- Downloadable résumé, email, and LinkedIn contact paths
- Accessible navigation, reduced-motion support, and keyboard focus states
- Custom social sharing image
- Automated GitHub Pages deployment

## Run locally

```bash
npm install
npm run dev
```

Create a production build with:

```bash
npm run build
```

## Publish on GitHub Pages

1. Create a GitHub repository and push this project to its `main` branch.
2. In the repository, open **Settings → Pages**.
3. Under **Build and deployment**, choose **GitHub Actions**.
4. The included workflow will build and publish the site automatically.

The site uses relative asset paths, so it works from either a profile Pages URL or a project Pages URL.
